# preparacao-exames

Aplicação para administrar seus estudos de forma simples, combinando conteúdo e
questões, com **score** indicando grau de assimiliação de assunto.

![](./images/conteudo.webp)

![](./images/questoes.webp)

Execute a aplicação:

```bash
$ npm install
$ ng serve
```
